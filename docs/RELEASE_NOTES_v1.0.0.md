# Version 1.0.0 — prepared, not published

A curated KJS annotation-versus-sequence reproducibility package with ORIGINAL, RECONSTRUCTED and NEW code categories, a compact frozen evidence set and self-contained tests.

Fresh included-input validation reproduces 7,373 filtered rows, a 1,483-locus P1 scientific-table projection, 75-sequence/468-locus panel preference, seven complete-proteome reciprocal seed tests (6 reciprocal; 5 bilateral85 both directions), and 374 targeted domain records. Neighbour/context and archived v005 counts retain explicit verification-level labels.

Full native P1's 14 scientific tables were verified using external original inputs; only the manuscript-specific projection is self-contained in this compact package. The earliest global BLASTP command remains unrecovered. Original reannotation, full-Pfam discovery, all-genome orthology and biochemical activity are not claimed.
